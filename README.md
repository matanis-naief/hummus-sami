# חומוסיית סמי

אתר תפריט דיגיטלי רספונסיבי בעברית.

## הפעלה

1. חלצו את קובץ ה-ZIP.
2. פתחו את הקובץ `index.html` בדפדפן.
3. כדי לערוך את המנות, המחירים והטקסטים, פתחו את `script.js` ואת `index.html`.

## קבצים

- `index.html` — מבנה האתר
- `style.css` — עיצוב מלא ורספונסיבי
- `script.js` — תפריט דינמי, ניווט ואנימציות

## התאמות חשובות

יש להחליף:
- מספר WhatsApp
- כתובת המסעדה
- אימייל
- קישורי רשתות חברתיות
- תמונות רקע
- שעות פתיחה
